## How it's made

- **Nothing on screen is mocked up.** `capture/` drives the real a11y-loop CLI and its demo pages with Playwright: keyboard walks, five-pass renders, `audit`, `diff` and `contrast` runs, all saved as manifests in `src/data/`.
- **Gates hold the numbers.** `npm run verify` re-checks every on-screen number against its capture; `verify:palette` checks every colour pair with a11y-loop itself; `verify:flash` screens the render for SC 2.3.1 flashes with ffmpeg.
- **One idea per beat.** `<Beats>` owns scene switching so only one layout exists at a time, and `<Stage>` keeps a safe box clear of the caption plate.
- **One script, three outputs.** `src/captions/script.json` feeds the ElevenLabs narration, the burned-in open captions and the SRT/VTT sidecars.
- **An accessible film.** Open captions, audio-description-first narration, a reduced-motion master, and no sound that carries meaning on its own. Music made with Suno.

## Make your own

Needs Node 22+ and `ffmpeg`. Clone [a11y-loop](https://github.com/ChanMeng666/a11y-loop) as a sibling folder (or set `A11Y_LOOP_REPO`).

```bash
npm install
npm run capture                  # capture everything from the real tool
npm run dev                      # preview in Remotion Studio (silent until audio exists)
cp .env.example .env             # add ELEVENLABS_API_KEY
npm run generate-audio           # narration and effects
npm run render                   # out/a11y-loop-promo.mp4
npm run captions                 # .srt and .vtt
npm run verify && npm run verify:palette && npm run verify:flash
```

Not in the repo: the captured media in `public/` (regenerated by `npm run capture`) and the music, which you bring yourself as `public/bgm.mp3` (prompts in [docs/suno-prompt.md](docs/suno-prompt.md)).
